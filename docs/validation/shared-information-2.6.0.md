real uploaded folders. Actual CLI output creates artifacts, revisions and posts;
canonical validation checks browser-authored reply bytes.

1. Two pinned messages follow one artifact through a new reading and later
   disconnection. Recorded message bytes/data stay unchanged. Both cards and
   declared declarative drawing update; old observation age remains stale.
2. Plain messages carry independently sourced values without any package.
   Commands, paths and HTML-like provenance remain escaped inert text.
3. Native submit force-reads only the source message's declared artifacts. A
   changed head refuses the old review with no new message; refreshing and
   reviewing again writes a canonical-valid source/hash/head-bound answer.

   context. Downloads retain exact reviewed heads. Historical replies lacking
   required review bindings are visibly invalid. Missing source keeps recorded
   fallback. No browser approval travels with copied files.

   files are consistently excluded. Physical scope and direct-publisher controls
   prevent foreign current data from entering renderer context.
6. Freshness expires with board refresh disabled. Future/unknown observations,
   stale data with recent availability, incomplete/corrupt/missing sources,
   offline forks/explicit merge, limits and UUID copy identity have focused tests.
7. Source disclosures survive refresh; superseded review drafts are discarded.

## Findings resolved during integration

- Shared state joins render identity and native pre-submit review checks.
- Direct publisher validation and exact16KiB UTF-8 boundaries match Python/JS.
- Uploaded `.txt` files under state cannot bypass the state resolver.
- Recorded/latest source disclosures have distinct reconciliation identities.
- Initial drawing does not consume the first input event's rate limit.
- Missing/damaged optional source bytes cannot authorize historical message
  withdrawal. Actual post/tamper/read/validate/repair controls retain original
  bytes; known verified snapshot/scope/contract mismatches remain invalid.
- Unchanged immutable byte snapshots reuse hash/parse verification; repeated
  references share bounded resolution work. Native reply checks force fresh reads.
